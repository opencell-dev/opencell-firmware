# Security

## Maintainer

Devin Frederick ([@dfrederick15](https://github.com/dfrederick15), devin@k4ozi.com) is the sole project and security maintainer of
this repository and of the OpenCell project ([opencell-dev](https://github.com/opencell-dev)). Security reports, fixes and releases go through the maintainer.

## Reporting a vulnerability

Please report security problems privately, not in a public issue: open a private advisory on GitHub (Security > Report a vulnerability)
or email devin@k4ozi.com. Include the affected component, the version or commit, and the steps to reproduce. You should get an answer
within a week.
